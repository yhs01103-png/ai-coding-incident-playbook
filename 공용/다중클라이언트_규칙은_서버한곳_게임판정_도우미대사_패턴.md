# 앱·웹 두 클라이언트가 같은 규칙을 쓸 때 — 판정·대사는 서버 한 곳, 클라이언트는 보여 주기만

## 문제

처음엔 앱 하나라 "기록으로 계산하는 값"(배지, 연속 기록, 체력, 콤보, 안내 문구)을 앱 로직 레이어에서 계산해도 충분하다.
그런데 웹(다른 언어·다른 프레임워크) 클라이언트를 따로 만드는 순간 **같은 규칙이 두 벌**이 된다.
한쪽만 고치면 같은 계정인데 앱과 웹이 다른 콤보·다른 체력·다른 안내를 보여 준다.

**실측(RVS_App, 2026-11-02~06)**: 격파(오늘의 몬스터·보스 체력 3칸·콤보·도감) 판정을 앱 `logic/battle.dart`에 먼저 만들었다.
같은 날 웹을 Flutter가 아닌 Vite+TypeScript로 따로 만들기로 하면서 판정을 서버 `battle.py`로 옮겼다(앱은 응답 읽기만).
뒤이어 만든 도우미(규칙 기반 안내 문구)는 처음부터 서버 한 곳(`POST /helper`)에 두어 앱·웹이 같은 말을 한다.

## 언제 서버로 옮기나(판단표)

| 조건 | 서버 한 곳 | 클라이언트 계산으로 둠 |
|---|---|---|
| 클라이언트가 둘 이상(언어가 다르면 특히) | ✅ | |
| 나중에 보상·과금이 붙는다(크레딧, 해금) | ✅ 부정 방지도 서버 몫 | |
| 규칙·문구를 자주 바꾼다 | ✅ 배포 한 번으로 양쪽 반영 | |
| 기기에만 의미가 있는 값(알림 본 여부, 연출 속도) | | ✅ 기기 저장 |
| 오프라인에서도 바로 보여야 한다 | | ✅ (서버 결과를 캐시) |

## 패턴

1. **계산은 순수 함수 하나**: `compute_x(입력 목록, 기준일) -> dict`. DB·네트워크를 모르는 함수라 시험이 쉽다(클라이언트에 있던 시험 사례를 그대로 서버 시험으로 옮긴다).
2. **엔드포인트는 읽기 전용 + 재료 수집만**: 기존 표를 읽어 재료를 모으고 `compute_x`에 넘긴다. **DB 변경 없이** 시작한다(새 표가 필요해지면 그때).
3. **기준일은 클라이언트가 보낸다**(`?day=YYYY-MM-DD`): 서버 시각대와 사용자 시각대가 다르면 "오늘"이 어긋난다. 저장 시각에 시간대가 없으면 배포 서버(UTC)에서 자정~오전 9시가 하루 밀린다 — 배포 전에 `TZ`나 저장 형식을 정한다.
4. **클라이언트 모델은 fromJson만**: 앱 로직 레이어에는 응답 모델만 남기고 계산 함수를 지운다. 클라이언트 시험은 "응답을 읽는다"로 바꾼다.
5. **"한 번만 알림" 같은 기기 상태는 클라이언트에**: 서버는 도감 항목에 고정 id(`monster:<세션>`, `boss:<세션>`)를 주고, 클라이언트는 본 id 집합만 기기에 저장한다.
6. **안내 문구(도우미)도 같은 원칙**: `{where, 화면 맥락}` → `{name, messages:[{id, text, action:{kind,…}}]}`. 클라이언트는 말풍선과 버튼만 그리고, `action.kind`(open_profile/memo/open_boss…)를 자기 화면 이동에 잇는다. 사용자가 쓴 글(고민 등)은 **주소(쿼리)가 아니라 본문**으로 보낸다.

## 함정

- **규칙을 바꾸면 과거 판정도 바뀐다**: 판정이 "그날의 몬스터 = 날짜 해시로 고른 풀 항목"처럼 매번 다시 계산되는 구조면, 고르는 규칙(예: 직업 우선)을 바꾸는 순간 지난날 격파가 보스로 바뀐다(RVS 실측 1건). 과거를 고정하려면 그날 고른 것을 저장해야 한다 — 바꾸기 전에 감수할지 정한다.
- **한 번 옮기고 나서 클라이언트에 계산을 다시 들이지 않는다**: "빨리 보이게"를 이유로 클라이언트에 규칙 복사본을 두면 원점이다. 빠르게 보이려면 서버 결과를 캐시한다.
- **메모리·네트워크 실패에 화면이 막히지 않게**: 판정·대사 요청이 실패하면 그 줄/말풍선만 숨기고 나머지 화면은 그대로 쓴다.

## 체크리스트

- [ ] 계산 함수가 순수 함수이고 서버 시험이 있다(클라이언트 사례 이식)
- [ ] 엔드포인트가 읽기 전용이고 DB 변경이 없다(필요하면 따로 승인)
- [ ] 기준일을 클라이언트가 보내고, 서버 시각대 문제를 배포 문서에 적었다
- [ ] 클라이언트에는 모델·표시만 남았다(계산 함수 삭제)
- [ ] 사용자 글은 요청 본문으로만 보낸다
