# 서버 없이 붙이는 게임화 — 앱이 기록으로 배지를 계산하고, 배지가 테마 팩을 여는 패턴

## 언제

이미 기록(메모·실행 이력)이 서버에 쌓이는 앱에 "실제 앱·게임 같은" 재방문 동기(배지·해금 스킨)를 붙이고 싶은데,
DB 스키마를 바꾸거나 서버 배포를 다시 하고 싶지 않을 때. Flutter 기준이지만 구조는 프레임워크 무관.

## 구조

| 조각 | 레이어 | 하는 일 |
|---|---|---|
| 배지 정의·계산 `computeBadges(records, now)` | logic(순수 함수) | 기록 목록 → 배지마다 현재 값·목표. 연속 일수는 `now`를 인자로(시험이 고정) |
| 팩 정의 `ThemePack{label, unlockedBy}` | logic | 이름과 여는 배지만. 색·글꼴은 모른다 |
| 팩 겉모습 `Skin{light, dark, titleFont, texture}` | ui | 색 토큰 두 벌 + 제목 글꼴 + 배경 무늬. logic을 모른다 |
| 팩→겉모습 매핑, 설정 칸, 획득 알림 | ux | 두 레이어를 잇는 유일한 곳 |
| 고른 팩·이미 알린 배지 저장 | 기기 저장(영속) | 파일/Prefs, 화면은 파이프라인 감싸개로만 |

앱 뼈대(전역)가 "고른 팩"과 "밝기"를 둘 다 구독해 테마를 다시 만든다 — 설정 화면 스택은 그대로 유지된다.

## 규칙

1. **획득은 계산, "봤다"만 저장.** 배지 값은 매번 기록에서 센다(집계 표 없음 → 이중 계산·불일치 없음). 저장하는 건 "이미 알려 준 배지" 집합뿐.
2. **한 번 연 해금은 안 잠근다.** 해금 = 지금 계산된 획득 ∪ 저장된 "봤다" 집합. 사용자가 기록을 지워도 쓰던 스킨이 갑자기 잠기지 않는다.
3. **알림은 기록을 불러올 때, 한 번에 묶어서.** 첫 실행에 기존 기록만으로 여러 개가 한꺼번에 열리면 토스트 하나: "배지 획득: A, B · 팩 X 열림".
4. **목표는 서버 목록 상한보다 작게.** 기록 API가 최근 N개만 주면 그보다 큰 목표(“역산 500번”)는 영영 못 연다.
5. **스킨은 제목 글꼴만 바꾼다.** 본문까지 손글씨로 바꾸면 긴 글을 못 읽는다. 한글 글꼴은 개당 2~8MB — OFL 확인, Regular만 넣고 굵기는 합성, 8MB급은 빼고 2~3MB급으로.
6. **배경 무늬는 이미지 대신 `CustomPainter`.** 줄·모눈·점·민무늬를 테마 확장(`ThemeExtension`)의 값으로 두면 용량 0, 다크에서도 토큰 색을 따른다.
7. **잠긴 항목도 미리보기를 보여 준다.** 팩 타일은 그 팩의 색 점 3개와 그 팩 글꼴로 이름을 그리고, 잠겼으면 흐리게 + 자물쇠 + 여는 배지 이름.

> 클라이언트가 둘 이상(앱 + 언어가 다른 웹)이 되면 이 계산을 서버로 옮긴다 — `다중클라이언트_규칙은_서버한곳_게임판정_도우미대사_패턴.md`(RVS_App 2026-11-02 격파 판정 이전).

## 함정

- 다크 팔레트를 새로 만들면 "평행/보조 카드 바탕" 같은 옅은 색이 어두운 배경 위에서 탁해진다(남색 위 갈색). **실기기 다크에서 한 번씩 본다.**
- 위젯 시험의 `pumpAndSettle`은 계속 도는 애니메이션이 있으면 안 끝난다 — 공개 연출은 한 번만 도는 컨트롤러(차례는 `Interval`), 반복 깜박임은 잠깐 보이는 자리 표시에만.
- 앱 코드가 돌기 전의 시스템 시작 화면(Android splash)은 앱 안 테마 선택을 모른다 — 기기 밝기만 따른다. 팩마다 바꾸려면 네이티브 쪽에 값을 써 둬야 한다.
- 기기를 바꾸면 배지는 서버 기록으로 다시 계산되지만 "봤다" 집합은 사라져 알림이 한 번 더 뜬다. 해금 시점까지 남기려면 그때 서버 저장(스키마 변경).

## 시험

- 계산: 종류별 개수, 연속 일수(오늘 없으면 어제부터, 끊김), 0건.
- 해금: 기본 팩은 처음부터, 나머지는 여는 배지 있을 때만.
- 저장: 팩·"봤다" 집합 왕복(파일 구현).
- 알림: 새 배지는 한 번만, 두 번째엔 안 뜸.
- 설정: 잠긴 팩은 눌러도 그대로, 열린 팩은 고르면 바로 적용·저장.
